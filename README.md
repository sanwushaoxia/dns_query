# dns-query

用开源 DNS 工具库 [dnspython](https://github.com/rthalley/dnspython)（ISC 协议）从多个公共 DNS / DoH 解析域名 IP，方便自行挑选延迟较低的地址写入 hosts，加速访问 `github.com` 等站点。

查询结果可以交给 `src/apply-hosts.sh`，只改 `/etc/hosts` 里由本工具管理的标记区块，并在写入前备份。

## 工作方式

1. 同时向 Cloudflare、Google、Quad9、AliDNS、DNSPod、OpenDNS 查询 A / AAAA。
2. 再用 Cloudflare / Google / AliDNS 的 DNS-over-HTTPS JSON 接口补一轮，减轻本地 DNS 被污染的影响。
3. 可选：对 IPv4 做 `443` 端口 TCP 握手测速，挑出当前网络下更快的地址。

## 安装

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 用法

查询单个域名：

```bash
python3 -m src github.com
```

查询 GitHub 常用域名并按 TCP 延迟排序：

```bash
python3 -m src --preset github --fastest --ipv4-only
```

生成 hosts 片段（每个域名选一个当前较快的 IPv4）：

```bash
python3 -m src --preset github --fastest --ipv4-only --format hosts -o github.hosts
```

指定自己的 DNS：

```bash
python3 -m src api.github.com --dns 1.1.1.1 --dns 8.8.8.8 --no-doh
```

从文件读取域名：

```bash
python3 -m src --from-file presets/github.txt --format json
```

## src/apply-hosts.sh

`src/apply-hosts.sh` 用来把测速后的 IP 写进 `/etc/hosts`，加速访问 `github.com` 等站点。它**不会整文件覆盖** hosts，只维护一对标记之间的区块，写入前会备份。脚本在 `src/` 内，会自动回到仓库根目录调用 `.venv` 和 `presets/`。

```
# BEGIN dns-query managed
20.205.243.166       github.com
# END dns-query managed
```

先完成上面的「安装」，并保证项目里有 `.venv`（脚本固定调用 `.venv/bin/python`）。在仓库根目录执行：

```bash
chmod +x src/apply-hosts.sh    # 只需一次
./src/apply-hosts.sh --help
```

### 命令格式

```text
./src/apply-hosts.sh [动作] [域名...] [选项]
```

| 动作 | 默认 | 是否改 `/etc/hosts` | 说明 |
| --- | --- | --- | --- |
| `preview` | 是（省略动作时） | 否 | 查询、测速，只打印将要写入的区块 |
| `apply` | | 是（需 sudo） | 确认后写入标记区块 |
| `status` | | 否 | 显示当前已写入的标记区块 |
| `remove` | | 是（需 sudo） | 删除标记区块，保留其余 hosts |
| `restore` | | 是（需 sudo） | 用备份把整个 hosts 还原 |

未指定域名、`--preset`、`--from-file` 时，默认使用 `--preset github`。

### 推荐流程：只加速 github.com

先预览，确认 IP 后再写入：

```bash
./src/apply-hosts.sh preview github.com
```

典型输出：

```text
querying 1 domain(s)...
  github.com -> 20.205.243.166
# BEGIN dns-query managed
# Generated by dns-query at 2026-08-18 02:53 UTC
# CDN IPs change; re-run src/apply-hosts.sh to refresh.
20.205.243.166       github.com
# END dns-query managed
# dry-run only; run: ./src/apply-hosts.sh apply   to write /etc/hosts
```

预览无误后写入（会提示 `[y/N]`，再可能要求输入 sudo 密码）：

```bash
./src/apply-hosts.sh apply github.com
```

脚本会：

1. 再次查询并做 `443` 端口 TCP 测速，选出当前较快的 IPv4。
2. 备份 `/etc/hosts`（见下方「备份文件」）。
3. 删掉旧的标记区块，以及 hosts 里已经指向这些域名的其它行（避免同一域名出现两行、先匹配到旧 IP）。
4. 在文件末尾追加新的标记区块。
5. 尽量刷新本机 DNS 缓存（`resolvectl flush-caches` 等）。

不想交互确认时加上 `-y`：

```bash
./src/apply-hosts.sh apply -y github.com
```

写入后核对：

```bash
./src/apply-hosts.sh status
grep github.com /etc/hosts
```

浏览器或 `curl` 仍走旧 IP 时，可再执行 `sudo resolvectl flush-caches`，或新开一个终端后再试。

### 加速整组 GitHub 域名

`presets/github.txt` 里包含网页、API、raw、头像等常用域名：

```bash
./src/apply-hosts.sh preview --preset github
./src/apply-hosts.sh apply --preset github
```

或省略参数（默认就是 github 预设）：

```bash
./src/apply-hosts.sh preview
./src/apply-hosts.sh apply
```

也可以把命令行域名和预设、文件合并（去重后一起查询）：

```bash
./src/apply-hosts.sh apply --preset github gitlab.com
./src/apply-hosts.sh apply --from-file presets/github.txt example.com
```

### 撤销

只拿掉本工具写入的区块，其它记录不动：

```bash
./src/apply-hosts.sh remove
```

把整个 `/etc/hosts` 恢复成**第一次**执行 `apply` 之前的内容：

```bash
./src/apply-hosts.sh restore
```

`restore` 优先用 `/etc/hosts.dns-query.orig`；若没有该文件，则用最近一次的 `/etc/hosts.dns-query.bak`。

### 备份文件

| 文件 | 含义 |
| --- | --- |
| `/etc/hosts.dns-query.bak` | 每次 `apply` / `remove` 前覆盖保存的上一份 hosts |
| `/etc/hosts.dns-query.orig` | 本机第一次写入时留下的原始 hosts，之后不再覆盖 |

不要手改标记行 `# BEGIN dns-query managed` / `# END dns-query managed`。下次 `apply` 会按这对标记整体替换区块。

### 常用选项

| 选项 | 说明 |
| --- | --- |
| `--preset 名称` | 读取 `presets/名称.txt`，例如 `github` |
| `--from-file 路径` | 从文本文件读域名，一行一个，`#` 开头为注释 |
| `--dns IP` | 指定 UDP DNS（可重复），例如 `--dns 1.1.1.1 --dns 8.8.8.8` |
| `--no-doh` | 不做 DNS-over-HTTPS 补充查询 |
| `--timeout 秒` | 单个解析器超时，默认 `3` |
| `--hosts-file 路径` | 写入目标，默认 `/etc/hosts`，可用来先写到普通文件做试验 |
| `-y` / `--yes` | `apply` / `remove` / `restore` 时跳过确认 |

先写到当前目录、不碰系统文件的例子：

```bash
./src/apply-hosts.sh apply -y github.com --hosts-file ./github.hosts
```

指定 DNS、只查 `github.com`：

```bash
./src/apply-hosts.sh preview github.com --dns 223.5.5.5 --dns 8.8.8.8 --no-doh
```

### 注意

- 改系统 `/etc/hosts` 需要本机管理员权限；脚本在无法直接写入时会调用 `sudo`。
- 不要把记录手抄进 `127.0.0.1 localhost` 那一行。
- CDN 地址会变。访问变慢或打不开时，重新执行 `./src/apply-hosts.sh apply github.com` 即可刷新。
- `preview` 只打印计划内容，**不会**修改 `/etc/hosts`。要真正添加 `20.205.243.166  github.com` 这一行，必须执行 `apply`。

## 内置预设

| 预设 | 文件 | 说明 |
| --- | --- | --- |
| `github` | `presets/github.txt` | GitHub 网页、API、raw、头像、部分静态资源域名 |

可按同样格式新增 `presets/*.txt`，一行一个域名。
